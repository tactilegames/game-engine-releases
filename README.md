# Tactile Game Engine downloads

This repository contains public Tactile Game Engine installers and update metadata. The application source, project tracking, and support material are not hosted here.

## Latest stable installers

- [Windows x64](https://github.com/tactilegames/game-engine-releases/releases/latest/download/TactileGameEngine-Windows-x64.exe)
- [macOS Apple silicon](https://github.com/tactilegames/game-engine-releases/releases/latest/download/TactileGameEngine-macOS-arm64.dmg)

After installation, sign in with your Tactile account. Contact Tactile support if you need help.

Until the installers are signed, each release's notes say how to open them (macOS: System Settings → Privacy & Security → *Open Anyway*; Windows: *More info* → *Run anyway*) and that a macOS install is updated by downloading the next release.
